# UI RaHel (Wear)

- **Layout:** todas las pantallas usan `ScalingLazyColumn` + `WearContentPadding` para adaptarse a redondas, cuadradas y pantallas con poco alto.
- **Iconos:** Material Icons Extended (corazón, alerta, ciencia/SEED, volver, check). Sin emojis.
- **Navegación:** `CompactChip` con icono + etiqueta corta en inicio; `BackChip` consistente.
- **Estado:** anillo de color (`StatusRing`) según `AlertLevel`.
- **Tema:** fondo oscuro, acento azul, tipografía Wear Material.
